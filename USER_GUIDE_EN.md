# The Caller's Recording Studio — Guide (English Edition)

## 1. The Goal: Producing an MP3 Calling Track

Welcome to the Caller's Recording Studio: you bring the music
and the voice; the studio keeps the figures dancing in sync
with the beat and prompts each call; your recorder captures
voice plus music — the finished calling track.

The end product of this system is a finished calling track (MP3):
background music plus your spoken calls. The system keeps the
dancing figures synchronized to the music beat — you simply read
each call at the right moment, in rhythm.

## 1.1 How to Operate

A. **Collect calls**: gather the calls you will use (~120) into
   the sequence. Any of four input methods:
   - Key: tap the input box and type
   - Selection: tap the Calls button on the right, pick from list
   - Paste: paste a prepared list of calls
   - Voice: hold the round button and speak (see Section 2)
B. **Detect the beat**: tap "Beat Test" (lower left) while your
   chosen music plays. Once the tempo is detected, the figures
   dance to it, and the header / BPM display / beat button flash
   in time with the music — helping you internalize the rhythm.
C. **Record**: start your (external) recorder, press Play.
   The screen prompts the next call; read each one at the right
   moment until the end.
D. **Finish**: stop recording, listen back; repeat B–C until
   satisfied.

## 2. Voice Recognition

### 2.1 Start at Sequencer → Setting, bottom block "Speech Recognition"

Top to bottom:

- Title: Offline, high-accuracy speech recognition (free)
- **Noise suppression slider**: in a noisy room (AC/fridge)
  slide right until background noise no longer produces words
- **Prefix/Suffix threshold** and **Call-table threshold**
  sliders: right = strict (fewer false hits, more misses),
  left = loose. Blue hints appear while dragging.
  All settings are remembered across restarts.
- Silence gate, Consonant boost: checkboxes

### 2.2 New controls on the Sequencer screen (appearance)

Three rows on the initial screen (no table open):

- **Row 1**: input box (white) + three buttons outside on the
  right:
  - **X**: clears the screen — text, accumulation draft and
    pipeline displays; the keyboard stays (SOP: tap X before
    voice input, accumulate, then Enter)
  - **Open (📁)**: choose/create/manage your caller
    directories and tables (opening requires a password: the
    first one you enter becomes the password; "Forgot
    password" clears it for a reset)
  - **Round button (🎙)**: voice entry. With a table open it
    is ready (black border); hold → blue = listening (area
    turns yellow); release = finalize
- **Row 2**: "Tap Calls to SELECT Call" (white box, tap =
  selection page)
- **Row 3**: "Tap 📁 for VOICE INPUT" (white box, display
  only — tap the real 📁 button on row 1 to open a table)
- Rows 2-3 vanish once a table is opened (and return when
  back at the initial screen); only row 1 remains

### 2.3 Speaking a call

1. Open the level's **token table** (non-Only, sorted by
   fingerprint — fastest lookup)
2. Hold the round button, read the call at normal volume
3. The recognized standard call appears in the box; release
   (the keyboard pops up automatically — Enter is one tap away)
4. Press Enter — the figures execute the call
5. Re-speaking while holding replaces the last entry;
   releasing and pressing again appends

### 2.4 Three tricks for hard-to-recognize calls

A. Speak again, biting the initial consonant (sw-, sp-, ex-)
B. Split into syllables: "Extend" as "ix · tend",
   "Dosado" as "do · sa · do"
C. Re-record that call in the Only table with your natural
   pronunciation (select row → hold the round button → confirm)

### 2.5 Directories and table management (your library)

**First-time setup (three steps):**
1. On the Open screen type your name → **Create Directory**
   (creates an empty directory, no level question)
2. Your 📁 directory appears ("0 tables"); tap once to select,
   tap again (or Open) to enter
3. Inside, two main actions:
   - **New Table**: choose level + table kind —
     **Only table** (sorted by standard call; for building,
     selection, recording) or **token table** (sorted by
     fingerprint; **use this while calling**). Build several
     levels side by side in one directory
   - **Import Table**: pick a source —
     · **Phone file manager**: choose a .ysb file; the table
       lands in the current directory
     · **Another caller's directory**: whole-table copy

**Daily management (two levels, matched to what is selectable):**

Root level (directories are selectable):
- Tap a directory once = select (highlighted), again = enter
- With one selected: **Delete** (whole directory; password +
  strong confirmation when it holds tables), **Rename**
  (renames the directory; every table inside moves untouched,
  contents and password included)
- **Create Directory** always available
- No table actions appear here — nothing else is selectable

Inside a directory (tables are selectable):
- With a table selected: Delete / Rename / Save As / **Export** /
  Sort-Save-As
- **New Table** / **Import Table** always available
- Deleting a table never deletes its directory

Files and notices:
- Export: the built-in browser picks the location (starts at
  storage root, big "⬆ Up" button; the filename is the bare
  table name, e.g. PSfix_Only.ysb); you can create a folder
  on the spot (type a name, Enter — it enters the new folder)
- **Reminder when distributing to others**: other level
  tables (Ms_Only etc.) get their "standard call" column
  generated by the recipient's own system; only PSflix_Only
  has no local source — **we must carry it over**. Choose the
  "**For others**" mode when exporting: it carries the
  standard-call column only and leaves the recognition column
  empty — voice fingerprints are personal, filled by the
  recipient's own voice. The "Full backup" mode (recognition
  column included) is for your own backup only
- Every result or error is a centered large-text dialog
  dismissed by OK

**Passwords:**
- One password per caller directory; opening/deleting verifies
- First entry sets it; "Forgot password" clears it for a reset

### 2.6 Selection input (Calls page)

- Tap **Calls**; tick levels (e.g. Plus) or tick **PSfix**
  (lists the standard calls of your tables)
- Tap a call: variants open a sub-call sheet — its first row
  is the bare call (e.g. Square Thru = 4 hands by default;
  append a number on the keyboard for Square Thru 6)
- Picked calls **append** to the input box — compose
  prefix + call + suffix (square thru + 6; 1/2 + girls run)
- Clear with **X** before composing a new one
