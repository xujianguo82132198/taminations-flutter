口令员的录音棚
使用速览(2026-10-15版)

您在这间"录音棚"里录制成品口令曲(MP3): 汇集口令 → 配乐测节拍 → 小人随拍起舞 → 按提示朗读 → 录音机同步录制。 以下功能都是这间录音棚的设备。

一、第一次建立自己的资料库(三步)

步骤操作结果
1打开画面,输入您的名字,按 建目录 只建空目录,不问级别
2点 📁 您的目录(显示"0表")进入进入空目录
3在里面 新建表 或 引入表资料库起步

新建表:两种表型

表型排序用途
Only 表
(如 plus_Only)		标准口令排序 建表、选择法、录声纹记号
记号表
(如 plus)		记号排序 喊口令检索用——喊什么级别就打开该级别的记号表

同一目录可放多个级别的表:连按几次"新建表", 分别选 ms / plus / a1 …… 各级 Only 表与记号表并存。

引入表:两种来源

按 引入表 先问您:

  • 手机文件管理器——选 .ysb 文件,表落到当前目录;
  • 其他口令员目录——把别人的表整张拷贝过来。

二、选文件位置:自建浏览画面

导出/导入选位置时,出现自己的浏览画面:

  • 从存储根目录开始——您的目录(如 01-XJG)一眼可见, 不会再困在"下载内容"里;
  • 顶部全宽大字 ⬆ 返回上级 钮(根目录时变灰,不会迷路);
  • 系统目录(Android)自动隐藏,防止误存;
  • 导出的文件名只有表名(如 PSfix_Only.ysb),不带目录。
第一次使用会提示"所有文件访问"授权——按"去授权", 在系统页打开开关,返回即可(一次就好)。

三、喊口令(语音)

  1. 打开该级别的记号表(非Only表,记号排序)
  2. 按住圆钮 🎙,正常音量读出口令(输入框变黄=正在聆听)
  3. 识别出的标准口令进输入框,松手确认,按回车执行
  4. 同一按住期内重喊=更换最后一句;松手后再按=继续累加

难识别口令的三招

  1. 重喊一遍,开头辅音咬重(sw-、sp-、ex-)
  2. 拆音节分两拍喊:Extend 喊"ix · tend",Dosado 喊"do · sa · do"
  3. 还不行:到 Only 表给该口令重录一笔您平时的自然念法

四、选择法输入(Calls 页)

  • 点 Calls,级别区勾级别(如 Plus),或勾 PSfix (列您表里的标准口令)
  • 点口令:含变体的弹出子口令单(已自动去掉系统带的 "from"尾巴,选上的都能执行)
  • 选中的口令累加进输入框——可拼"前缀+口令+后缀" (如 square thru + 6;1/2 + girls run)
  • 拼新口令前,先用 X 钮清空

五、配乐与节拍

  • 点"测音乐节拍"+同时播音乐:测出后小人按节拍起舞, 表头/节拍显示/检测钮随拍大面积闪烁——帮您踩准节奏
  • Settings→语音识别:噪声抑制条、前缀/后缀门槛、口令表门槛 (右=严,左=松;自动记忆)

六、口令(密码)

  • 每个口令员目录一套口令:第一次输入即设定, 打开/删除要验
  • 忘了按 忘记口令 清除重设

七、所有提示都是居中大字框

结果和错误都显示在屏幕中央大字对话框,点"确定"才消失—— 不会看不清就溜走。
