# Taminations：BPM 检测 + 语音识别容错匹配 + 讯飞离线集成方案

## 场景与假设
- 舞会现场：音乐持续播放，口令员用**英文**喊口令（不同口令员口音各异）
- **容错处理的理解**（你未确认，我按最合理解释执行）：把识别结果与词库中**每一个口令**做模糊匹配纠错，自动纠正口音/音乐背景导致的识别偏差，适配不同口令员。若你原意是"按口令员建个人档案"或"候选确认制"，实施前告诉我，设计已预留调整空间
- 讯飞账号 + 离线英文听写 SDK 可用（Phase 2，需你提供 AppID 与 SDK 包）

## 本轮交付（Phase 1，纯 Dart + 一个新依赖，不依赖讯飞资料）

### 1A. BPM 检测 + 应用到动画速度
- `pubspec.yaml` + `record` 包（流式 PCM，权限两端已配好，`TamUtils.canListen` 限定 Android/iOS）
- 新文件 `lib/sequencer/bpm_detector.dart`（纯 Dart）：22050Hz PCM → 分帧 → `scidart` FFT 频谱通量 → 自相关估节拍（60–200 BPM，偏好方块舞区间 100–160，倍频校验）；每秒刷新、12 秒定稿，精度 ±2–3 BPM
- 新文件 `lib/sequencer/bpm_button.dart`：音符按钮放在 Sequencer 输入行麦克风旁；点击先停语音识别（麦克风互斥）→ 采集 12 秒实时显示 → 显示最终 BPM
- 应用：`Settings.musicBpm`（新增，默认 120）+ `Settings.speed = 'Music'`；播放中同时 `BeatNotifier.setSpeed(60000/bpm)` 实时生效
- 改动：`settings.dart`、`dance_model.dart:98`（speed 加 Music 分支）、`settings_page.dart:308`（速度单选加 "Music (128)"）、`animation_page.dart:380`（显示 BPM 值）、`sequence_frame.dart:296`（加按钮）

### 1B. 语音识别容错匹配层（引擎无关，现有 en_US 识别立刻受益，讯飞接入后直接复用）
- 新文件 `lib/sequencer/fuzzy_matcher.dart`（纯 Dart）：
  - **三级匹配**：① 全词命中词库 → 走现有精确路径（不变）；② **词级纠错**：不在词库的词按 Levenshtein 编辑距离映射到最接近的词库词（短词容差 1、长词容差 2–3，阈值随词长分级）；③ **短语级匹配**：纠错后的短语与 `Words.normalizedCallIndex`（已存在的全口令规范化索引）做相似度评分，返回排序候选
  - 置信度 ≥ 0.75：自动采用纠错后的口令并提示"已识别为：Spin Chain Thru"；低于阈值：保留现有"最佳猜测"提示样式，附带前 3 候选
- 集成点：`sequence_frame.dart:194-212` 识别结果处理处，替换现在的"全词命中才通过"硬判断；输入框手动输入同样受益
- 单元测试 `test/fuzzy_matcher_test.dart`：典型口音误听用例（如 "spine chain"→"spin chain"、"doe sa doe"→"dosado"、"sashade"→"sashay"）+ 噪声词混入用例

### 测试与验证
- `test/bpm_detector_test.dart` + `test/fuzzy_matcher_test.dart` 均为纯 Dart 单测（合成音轨/合成文本，无需模拟器）
- `flutter analyze` + `flutter test` 全绿；现有语音输入、口令加载、动画不回退
