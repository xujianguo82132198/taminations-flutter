# 用科大讯飞听写流式版 WebAPI 替换 speech_to_text(对外 API 不变)

## 目标

`sequence_frame.dart` 除 3 行外零改动,`SpeechToTextProvider` 对外成员(`initialize`/`listen`/`stop`/`isAvailable`/`isListening`/`hasResults`/`lastResult.alternates`/ChangeNotifier 行为)保持不变;底层全部替换为讯飞语音听写(流式版)WebSocket API(英文 `en_us`),并从 pubspec 移除 `speech_to_text`。

## 新增文件

1. **`lib/sequencer/xfyun_speech_to_text.dart`** — 兼容 API 的 Provider:
   - `class SpeechToTextProvider extends ChangeNotifier`,默认构造(不再接收 `SpeechToText` 参数)
   - `initialize()`:通过 `record` 请求麦克风权限、校验讯飞凭据已配置 → 置 `isAvailable`
   - `listen({localeId, partialResults, soundLevel, listenFor, pauseFor, onDevice, ...})`:`en_US`→`en_us` 映射;启动录音(16k/单声道/PCM16)→ 每 40ms 一帧(1280 字节)经 WebSocket 上传;`listenFor` 到时自动收尾;`pauseFor` 用振幅静音检测(连续 5s 低于阈值)自动收尾;`soundLevel: true` 时更新 `lastLevel`
   - `stop()`:发尾帧 → 等最终识别结果 → 写 `lastResult` → `notifyListeners()`;`cancel()`:丢弃结果关闭会话
   - 只实现调用方用到的成员,`stream`/`locales` 等未用成员做最小桩
   - 本地定义同名结果类型:`SpeechRecognitionResult{alternates}`、`SpeechRecognitionAlternative{recognizedWords, confidence}`
2. **`lib/sequencer/xfyun_iat_client.dart`** — 讯飞协议实现:
   - `wss://iat-api.xfyun.cn/v2/iat`;鉴权按官方算法:HMAC-SHA256 签名(host/date/request-line)→ base64 authorization 查询参数
   - 首帧 `common{app_id}`+`business{language: en_us, domain: iat, dwa: wpgs}`;音频帧 `data{format: "audio/L16;rate=16000", encoding: raw, audio: base64}`;尾帧结束标记
   - 动态修正(wpgs)解析:`pgs=apd` 追加、`rpl` 按 `sn` 替换,拼接 `ws[].cw[].w` 得最终文本;`cw` 词级候选可拼出 1~2 个 `alternates` 候选
   - 讯飞错误码(code≠0)→ 置 `hasError`,由现有 SnackBar 逻辑展示
3. **`lib/sequencer/xfyun_keys.dart`** — AppID/APIKey/APISecret 常量,加入 `.gitignore`;同时支持 `--dart-define XF_APP_ID/XF_API_KEY/XF_API_SECRET` 覆盖(仓库是开源项目,模板文件 `xfyun_keys_template.dart` 提交,真 key 不入库)

## 修改文件

- **`pubspec.yaml`**:移除 `speech_to_text`;新增 `record: ^5.1.0`(PCM 录音流+振幅)、`web_socket_channel: ^3.0.0`、`crypto: ^3.0.0`
- **`lib/sequencer/sequence_frame.dart`**(仅 3 处):
  - L28-29:两个 speech_to_text import → `import 'xfyun_speech_to_text.dart';`
  - L155:`SpeechToTextProvider(SpeechToText())` → `SpeechToTextProvider()`
  - 其余全部不动(hasResults/lastResult.alternates/listen 参数/stop/isAvailable/isListening/ChangeNotifierProvider 集成)

## 权限(已具备,无需改动)

Android `RECORD_AUDIO` 已声明;iOS `NSMicrophoneUsageDescription` 已有(`NSSpeechRecognitionUsageDescription` 保留无害,云识别不依赖它)。

## 验证

1. `flutter pub get` + `flutter analyze` 无新告警
2. `flutter build apk --debug` 通过
3. 用户提供讯飞凭据(需在讯飞控制台开通"语音听写(流式版)",每天 500 次免费额度)后真机验证:点麦克风说英文口令(如 "swing thru")→ Sequencer 正确收到 call;无网/无 key/拒绝权限时错误提示正常
4. `debugLogging: true` 时输出原始 WebSocket 报文便于联调

## 风险提示

- Key 嵌入 App 可被提取,免费额度有被刷风险(已按你的选择接受)
- 方块舞术语生僻,识别准确率依赖现有 `normalizeCall` + `Words.words` 词表匹配兜底,与原 Google 方案同水位
